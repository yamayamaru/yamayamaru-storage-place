ファイル転送方法

MSVP98.EXEを起動

MS-Kermitとプロンプトが出ます

受信は下記のコマンドを打ちます
set speed 9600
set recieve packet-length 1000
set file type binary
receive

ファイル転送が始まります
exitで終了

送信は下記になります
send filename
ディレクトリ移動はcd、ディレクトリ表示はdirです






LinuxのCkermitとのファイル転送

sudo apt-get install ckermit

受信
Ckermit側はこんな感じ
$ kermit

C-Kermit> set LINE /dev/ttyUSB0
C-kermit> set SPEED 9600
C-kermit> set parity none
C-kermit> set carrier-watch off
C-kermit> SET PREFIXING ALL
C-kermit> SET STREAMING OFF
C-kermit> set file type binary
C-kermit> receive

先にCkermitの方をレシーブ状態にしておくこと

送信：
C-Kermit> set LINE /dev/ttyUSB0
C-kermit> set SPEED 9600
C-kermit> set parity none
C-kermit> set carrier-watch off
C-kermit> SET PREFIXING ALL
C-kermit> SET STREAMING OFF
C-kermit> send hogehoge.dat

高速通信するときはお互いフローコントロールをオンにする
C-kermit> set flow-control rts/cts
