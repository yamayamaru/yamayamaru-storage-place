ファイル転送方法

MSVP98.EXEを起動

MS-Kermitとプロンプトが出ます

受信は下記のコマンドを打ちます
set speed 9600
set receive packet-length 1000
set file type binary
receive

ファイル転送が始まります
exitで終了

送信は下記になります
send filename
ディレクトリ移動はcd、ディレクトリ表示はdirです

送信が止まってしまう場合は下記のように送信側のパケットの長さを調整
set send packet-length 90

WindowsのTeraTermとのファイル転送もできました
PC9801は機種によっては19200bpsや38400bpsでもファイル転送可能なようです




LinuxのCkermitとのファイル転送

sudo apt-get install ckermit

C-kermit> SET STREAMING OFF

C-kermit> receive

Windows(TeraTermからPC98)


TeraTermの設定

TeraTermのフリーコントロールは設定→シリアルポートの画面で
・スピード 9600
・データ    8bit
・パリティ  none
・ストップビット 1 bit
・フロー制御 RTS/CTS

を設定し新しいウインドウで接続を押す


受信：PC98

MSVP98を実行

set speed 9600
set parity none
set file type binary
set send packet-length 90
set receive packet-length 1000
set flow-control rts/cts

receive



PC98を受信状態にしてから
Teratermのファイル→転送→Kermit→送信を選択
ファイルを選択する画面が開くのでファイルを選択して開くを押す





Windows(PC98からTeraTerm)


TeraTermの設定

TeraTermのフリーコントロールは設定→シリアルポートの画面で
・スピード 9600
・データ    8bit
・パリティ  none
・ストップビット 1 bit
・フロー制御 RTS/CTS

を設定し新しいウインドウで接続を押す

Teratermのファイル→転送→Kermit→受信を選択
